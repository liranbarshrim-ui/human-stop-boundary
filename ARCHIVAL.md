## Intended archival path

This repository is prepared for persistent research archiving through GitHub Releases + Zenodo and Software Heritage.

A GitHub release should be created for each canonical DAR research version. Zenodo can archive each public GitHub release and assign a DOI. Software Heritage can independently preserve and identify the source tree.

## Provenance principle

The repository is the source of truth. Chat-pasted artifacts are not evidence until compared against a fresh checkout and executed.

The research record should preserve both the claims and the known limitations of each version. DAR is an active research prototype, not a production certification or independent security audit.
