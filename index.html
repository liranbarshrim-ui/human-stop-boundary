The Architecture of Accountability

When a decision becomes irreversible under uncertainty, someone must have the authority to stop it — by name.

This is not a tool.
This is the moment someone must decide whether to stop.

Most organizations avoid defining who that person is.

If this decision becomes irreversible —
your name will be the one that remains.

The only question is:
was it defined in advance — or assigned after?

Exposure If this decision causes harm —
responsibility will not remain abstract.

It will not be “we”.

It will resolve to a name.

If no name was defined in advance, accountability will be assigned after the fact.
“We” removes the need for a single person to stop.
The system cannot bear the cost.
Only a named individual can.
The Problem

No One Stops

“We” is where responsibility disappears.

“We” diffuses responsibility. It creates a gap where oversight exists in language but not in reality.

ProblemCharacteristicImpact
Many HandsAgency is diffusedNo one stops

Marking GapNo enforcement layerNo trigger
The Imperative

One Name

Critical outcomes must map to a single name. Not a function. Not a team. A person.

The Law

Responsibility Before Failure

Responsibility must exist before failure, not after.

The Threshold

Irreversibility

At the point of irreversibility, inaction is a decision.

The Authority

Stop Authority

If authority cannot be exercised in real time, it does not exist.

The Erosion

How Responsibility Disappears

Responsibility erodes gradually inside systems. The named person is a fragile achievement.

Reality

After the fact

After every failure, the same sentence appears:

“Someone should have stopped this.”

No one asks what the process was.
No one asks how many approved.

Only one question remains:

Who was supposed to stop it — and why wasn’t that defined in advance?

Who is named to stop an irreversible decision?
If no one is named — no one stops.

And when it fails — responsibility will not stay abstract.

Before your next irreversible decision —
who is explicitly named to stop it?
If you cannot name that person —
the system will not stop.
This is where systems fail — not because no one knew, but because no one was named.
This has already happened — in systems that passed every review.
The Model

Decision Accountability Record (DAR)

DAR exists to make this explicit — before the moment arrives.

The Decision

Name the stop — or accept the outcome

If this applies to a real system — the question is no longer theoretical.

Who is explicitly named to stop your next irreversible decision?

If this question does not have a clear answer — the system is already exposed.
