The Architecture of Accountability

When a decision becomes irreversible under uncertainty, someone must have the authority to stop it — by name.

Decision Authority Record (DAR) — defined by Liran Bar-Shrim.

Knight Capital Group — August 1, 2012 45 minutes. $440 million lost. No individual was named to stop execution.
If no one is named — no one stops.

The Test

A stop does not exist merely because it is documented.

It exists only when a named person ensures continuation is not possible without them.

If continuation is possible without them —
there is no stop.

This is not a tool.
This is the moment someone must decide whether to stop.

Most organizations avoid defining who that person is.

If this decision becomes irreversible —
your name will be the one that remains.

The only question is:
was it defined in advance — or assigned after?

Exposure If this decision causes harm —
responsibility will not remain abstract.

It will not be “we”.

It will resolve to a name.

If no name was defined in advance, accountability will be assigned after the fact.

And it will not be the system.

You already have decisions like this.
They just haven’t failed yet.

The Problem

No One Stops

“We” is where responsibility disappears. It diffuses agency until no individual feels the weight of stopping.

Every organization has people who approve. No organization names the person required to stop.

When no name exists, no stop exists. The system continues until it cannot be undone.

The Principle

One Name

Critical outcomes must map to a single name. Not a function. Not a team. A person — pre-committed, in writing, before execution becomes irreversible.

Responsibility without authority is punishment. Authority without responsibility is risk.

If you are held responsible
for a decision you were not able to stop,
that is not accountability.

That is punishment.

If someone can approve a decision
without being accountable for its outcome,
that is not authority.

That is risk.

If authority cannot be exercised in real time, it does not exist.

Responsibility doesn’t disappear.
It concentrates.
The Threshold

Irreversibility

A system can be technically safe and still proceed without anyone being required to stop it.

At the point of irreversibility, inaction is a decision.

The question is not how to stop. It is what makes continuation available. If continuation is available without a named release, there is no stop.

Reality

After the fact

After every failure, the same sentence appears: “Someone should have stopped this.”

No one asks what the process was. No one asks how many approved.

Only one question remains: who was supposed to stop it — and why wasn’t that defined in advance?

The Illusion

Documentation is not protection

Documentation without a name is not protection.

It is evidence.

It proves you knew the gap existed — and continued anyway.

No one is named. The name will be assigned later.

And it won’t be the system.

Who is named to stop an irreversible decision?
If no one is named — no one stops.

And when it fails — responsibility will not stay abstract.

Who is that name in your system today?

The Decision

Name the stop — or accept the outcome

If this applies to a real system — the question is no longer theoretical.

If you cannot name the person —
the system will not stop.

Who is explicitly named to stop your next irreversible decision?

If you cannot name the person — it is already happening.
