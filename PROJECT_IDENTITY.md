# Project Identity

## Canonical project name

**Decision Accountability Review (DAR)**

## Core governance artifact

**Decision Authority Record**

A Decision Authority Record is a named-authority artifact within the DAR framework. It identifies who holds refusal/stop authority before an irreversible effect.

## Naming rule

Use:

- **DAR** → Decision Accountability Review
- **Decision Authority Record** → the governance artifact
- **Human Stop Boundary** → the enforcement-boundary implementation/research prototype

Do not use **Decision Accountability Record** as an expansion of DAR.

## Why this distinction matters

The repository contains both conceptual/research material and an implementation boundary. Keeping the framework, governance artifact, and implementation clearly named makes the provenance record easier to audit and reduces ambiguity in citations, licensing notices, research references, and external review.

## Historical names

Git history contains earlier naming variants. Historical commits remain part of the immutable repository record and are not rewritten merely to normalize current terminology.

**Canonical as of the current repository:** Decision Accountability Review (DAR).
